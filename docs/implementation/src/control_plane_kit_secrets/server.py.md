This environment-bound process entrypoint creates app at module import. It loads key/credential files and may inspect or initialize SQLite custody; it is not the package root's lightweight import surface.

A database path is required; provider identity has a default. The explicit public control path is admitted first through [control.py](../../../../src/control_plane_kit_secrets/control.py). The local named initializer contains the existing private key/credential loaders followed by admit_provider_custody and returns the real stores plus admitted credentials. It is passed to the required-control create_app, which invokes it only after complete actual SDK host admission. Invalid public configuration or SDK collision performs no private reads/custody; invalid private loader configuration remains fixed ProviderConfigurationError. Exact retained schema/key/provider compatibility remains in custody.py, not health routes. Bind address, TLS termination and process supervision belong to the launcher.
