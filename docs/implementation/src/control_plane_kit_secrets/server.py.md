This environment-bound process entrypoint creates app at module import. It loads key/credential files and may inspect or initialize SQLite custody; it is not the package root's lightweight import surface.

A database path is required; provider identity has a default. The explicit public control path is admitted first through [control.py](../../../../src/control_plane_kit_secrets/control.py). The local named initializer loads the private key and credentials, passes the explicit parsed credential tuple to custody for one-time v2 policy seeding/migration, and returns the real stores plus credentials. It is passed to the required-control create_app, which invokes it only after complete actual SDK host admission. Invalid public configuration or SDK collision performs no private reads/custody; invalid private loader or seed configuration remains fixed ProviderConfigurationError/ProviderCustodyRejected. Exact retained schema/key/provider/policy compatibility remains in custody.py, not health routes. Bind address, TLS termination and process supervision belong to the launcher.
